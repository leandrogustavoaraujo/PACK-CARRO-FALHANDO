# Scanner no Celular — publicação GitHub

1. Extraia este pacote na raiz do seu repositório.
2. Mantenha `index.html`, `styles.css`, `palette.css` e a pasta `assets` juntos.
3. Publique pelo GitHub Pages apontando para a raiz do repositório.

Todas as imagens da landing foram convertidas para WebP e os caminhos no `index.html` já foram atualizados.
